"# Marcadinho-de-seu-ze" 
Mercearia do Seu Zé

Site institucional de uma página para a Mercearia do Seu Zé, pequeno comércio tradicional localizado no Centro Histórico de Curitiba.

O projeto foi pensado para funcionar como um cartão de visitas digital: facilitar a descoberta da mercearia por pesquisas no celular e, ao mesmo tempo, preservar a sensação de proximidade e confiança de um comércio de bairro.

Arquivos

index.html — página completa, com HTML semântico e CSS responsivo incorporado no próprio arquivo.

README.md — documentação do projeto e cadastro da equipe de desenvolvimento.

Como executar

Não é necessário instalar nada.

Basta abrir o arquivo index.html em um navegador moderno. O projeto não depende de frameworks, bibliotecas externas, banco de dados ou serviços pagos.

Decisões de design

1. Identidade visual

Foi adotada uma paleta em tons terrosos, bege e verde-oliva para remeter a madeira, café, produtos coloniais e ao aspecto tradicional de uma mercearia antiga.

A tipografia serifada nos títulos reforça a sensação de tradição, enquanto a tipografia do corpo permanece simples e legível em telas pequenas.

2. Mobile-first

A estrutura começa pensando em celular, com:

blocos empilhados;

botões com área confortável para toque;

conteúdo curto e direto;

navegação simples;

contraste adequado;

largura de leitura limitada para evitar textos muito extensos.

Em telas maiores, os conteúdos são distribuídos em colunas para aproveitar melhor o espaço.

3. HTML semântico e acessibilidade

O site utiliza elementos como:

header;

nav;

main;

section;

article;

footer.

Também foram incluídos:

hierarquia clara de títulos;

link “Pular para o conteúdo”;

estados visíveis de foco;

aria-label em elementos interativos quando necessário;

suporte a prefers-reduced-motion;

links de telefone e WhatsApp com ação direta.

Não foram utilizadas imagens externas no protótipo para manter o arquivo leve e evitar dependências. O layout já está estruturado para receber fotografias reais da mercearia em uma etapa futura.

4. SEO local

O index.html contém:

title descritivo;

meta description;

palavras-chave relacionadas à mercearia e à região;

menção textual ao Centro de Curitiba, Calçadão da XV de Novembro, café e produtos coloniais.

Para uma versão final, recomenda-se cadastrar e validar o estabelecimento no Google Business Profile e manter endereço, telefone e horário consistentes em todos os canais.

Informações que precisam ser confirmadas

O HTML identifica explicitamente os seguintes dados como placeholders:

endereço;

horário de funcionamento;

telefone;

número do WhatsApp;

links oficiais de Instagram e Facebook.

Antes da publicação, substituir os valores ilustrativos pelos dados reais do cliente.

Promoção

A “Promoção da semana” foi incluída como conteúdo demonstrativo.

O preço não foi inventado no HTML. A sugestão é atualizar o texto semanalmente com a promoção e o valor que estiverem valendo no balcão.
